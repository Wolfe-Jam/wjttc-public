## Failure Analysis Summary

| Failure Type | Servers Affected | Fix Difficulty |
|--------------|------------------|----------------|
| Naming (kebab vs snake_case) | Context7 | Easy |
| No emoji in descriptions | All except claude-faf-mcp | Easy |
| Path restrictions (security) | Filesystem | Expected behavior |
| Specialized tools (not file-based) | Memory | Expected behavior |
| Authentication required | GitHub, Heroku | N/A |
| Non-standard startup | Everything, Sequential | Unknown |

### Common Issues

1. **Naming Convention (SHOULD):** Most servers use kebab-case (`get-data`) instead of snake_case (`get_data`). MCP spec recommends lowercase_snake_case.

2. **No Emoji (SHOULD):** Zero emoji usage in descriptions across all Anthropic servers. This is a polish/UX improvement opportunity.

3. **Path Security:** Filesystem server correctly restricts access. This is a security feature, not a bug. Tests could be improved to configure allowed paths.
